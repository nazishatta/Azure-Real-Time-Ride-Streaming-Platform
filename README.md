# Azure-Real-Time-Ride-Streaming-Platform
End-to-end real-time data engineering platform using Azure Event Hubs, Databricks, PySpark Structured Streaming, ADLS Gen2, Delta Lake, and dimensional modeling for scalable ride-event analytics.

## Development Progress
- Implemented real-time ride ingestion and metadata-driven Bronze-to-Silver transformations using Azure Event Hubs, Databricks, PySpark, and Delta Lake.
